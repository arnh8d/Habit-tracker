  # Трекер привычек
  ___
  ### Описание проекта

  REST API для управления привычками с базовым функционалом: 
  добавление/удаление/изменение привычки, отметка выполнения, 
  получение списка привычек,
  получение статистики по привычкам 
  (история отметок - даты, текущий и максимальный стрик)
 
___
  ### Цель проекта
  Проект создан в целях практики использования Fastapi и базы данных.
